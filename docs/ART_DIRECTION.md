# 아트 디렉션 — Idle Ops

공유 월드 방치형 게임의 시각 톤과 캐릭터 카논을 고정합니다. 신규 아트는 이 문서와
[`ASSET_REQUIREMENTS_V3.md`](ASSET_REQUIREMENTS_V3.md)를 기준으로 검수합니다(v3에서 납품 규격이
768×768 제작 캔버스·자산별 `facing`·아틀라스/시퀀스로 바뀌었습니다; 구
`ASSET_REQUIREMENTS.md`는 v2 시점 기록).

## 1. 캐릭터 카논 — 향단이

현행 운영 스프라이트(`hyangdani-idle/run/strike.png`)가 정본입니다. 다음 인상은
변경할 수 없습니다.

| 요소 | 고정 사항 |
| --- | --- |
| 스타일 | 2D 애니메 셀 셰이딩, 얇고 어두운 외곽선, 부드러운 하이라이트 |
| 헤어 | 라벤더-실버 트윈 번 + 허리까지 흐르는 긴 머리, 보라 리본 |
| 눈 | 보라색 홍채, 또렷한 눈매 |
| 의상 | 화이트 테크웨어 재킷(오픈), 블랙 크롭탑, 화이트 카고 팬츠 + 블랙 스트랩·버클, 보라 포인트 스니커즈 |
| 액세서리 | 목에 걸친 헤드폰, 보라 네온 링 포인트 |
| 무기 | 대형 보라 사이버 해머(네온 스트립·원형 코어) |
| 체형 | 7~8등신, 긴 다리, 큰 신발 실루엣 |

금지: 헤어/눈/의상 색 변경, 무기 교체, 체형 왜곡, 성인/아동 방향 재해석. 리디자인이
필요하면 PO 승인 후 이 문서를 먼저 갱신합니다.

## 4. 실루엣과 가독성

- 320 CSS px 폭에서도 향단이·버그·랙이 서로 구분되어야 합니다.
- 얼굴은 화면 높이 150 px에서도 눈 위치가 읽히도록 단순화합니다.
- 무기와 머리카락이 실루엣의 좌우 균형을 만듭니다. 포즈마다 실루엣이 겹치지 않게
  프레임 간 간격을 유지합니다.
- 외곽선 두께는 내보내기 기준 2~3 px(@2x)로 통일합니다.

## 5. 해상도와 스케일

| 항목 | 값 |
| --- | --- |
| 화면상 향단이 높이 | 150~300 CSS px (`scene.js` clamp) |
| 제작 캔버스(v3) | 768×768, 셀 768×768 (아틀라스 4×2/4×3 또는 시퀀스) |
| 레거시 시트(v2) | 320×640 셀, 가로 스트립(기존 납품 호환용) |
| 시트 최대 크기 | 4096×4096 (`maxTexture`) |
| 화면상 버그 크기 | 42~80 CSS px |
| 버그 셀 | 512×512(v2) / v3는 납품 시 명시 |
| DPR 상한 | 2 (`LIMITS.dpr`) |
| 포맷 | PNG-32(sRGB, 알파), 프레임당 배경 없음 |

## 6. 셀·앵커·방향 규칙

- 모든 프레임은 **동일한 셀 크기**이며, 셀 경계에 캐릭터가 잘리지 않습니다.
- 발끝은 셀 **하단 중앙**에 맞춥니다. 엔진 앵커는 `[0.5, 1.0]`이고, v3는 프레임별
  `anchors[n]`도 지원합니다.
- 방향은 **자산별 `facing`**으로 선언합니다. 현행 향단이 원본은 **오른쪽**(`facing: "right"`),
  버그는 **왼쪽**(`facing: "left"`)을 봅니다. 엔진은 바라보는 방향과 이동 방향이 다를 때만
  좌우 반전합니다. 새 자산은 원본 방향을 그대로 적고, 반전 결과도 자연스러워야 합니다.
- 그림자·바닥 반사·UI 텍스트·프레임 번호를 이미지에 포함하지 않습니다(엔진이 그림자와
  효과를 그립니다).
- 상태 간 캐릭터 키(머리끝~발끝)를 일정하게 유지합니다. 전투 프레임만 무기 궤적으로
  캔버스가 넓어질 수 있으며, 이때도 몸통 크기는 동일합니다.

## 7. 서버실과 이펙트

- 배경: 어두운 네이비 서버실, 보라 네온 그리드 바닥, 벽면의 은은한 광원.
- 랙은 티어 색 LED 점으로 구분하고, 높이는 티어별로 다릅니다(캐시 < 앱 < DB < GPU < 양자).
- 열 70% 초과 시 화면 가장자리에 로즈색 비네트가 깔립니다(엔진 연출). 아트에 열 효과를
  굽지 않습니다.
- 파티클·슬래시·링은 보라/골드/시안 계열만 사용합니다.

## 8. 변경 절차

1. 카논 변경(디자인·팔레트·비율)은 PO 승인 후 이 문서를 먼저 수정합니다.
2. 규격 변경(셀 크기, 프레임 수, FPS)은 `sprites/manifest.json`·`engine/animation.js`와
   함께 갱신하고 테스트로 확인합니다.
3. 신규/교체 에셋은 [`ASSET_REQUIREMENTS_V3.md`](ASSET_REQUIREMENTS_V3.md) 체크리스트를 통과한
   뒤에만 `static/public/assets/sprites/`에 반입합니다.

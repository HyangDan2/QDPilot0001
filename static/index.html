      Reboot를 실행할까요?

      저장소 및 에이전트 연동 설정

      1. Idle Ops 서버 레지스트리에 저장소 ID, 관측 대상 ref, 공개 범위를 등록합니다.
      2. 읽기 범위의 GitHub 자격 증명을 수집기에 설정하고 첫 동기화를 실행합니다.
      3. 에이전트마다 대상 저장소와 전송용 토큰 범위를 지정합니다.
      4. 활동을 전송한 뒤 프로젝트와 에이전트 상태를 확인합니다.

      자격 증명은 서버의 연동 설정에서 관리합니다.
